# Attribution

## PapyriX — MIT

The e-ink waveforms (`src/lut_x3.h`), the UC8253 init sequence, the panel pin
map, the "BUSY is active-LOW on the X3" behaviour, and the resistor-ladder ADC
buckets for the six buttons are transcribed from
[PapyriX](https://github.com/bigbag/papyrix-reader) (MIT, Copyright (c) 2025
Dave Allie / bigbag).

Specifically `docs/x3-lut-waveforms.md`, verified against upstream:

> The UC8253 X3 uses 10 MHz SPI (20 MHz caused pixel damage in testing).
> Each 52KB frame transfer takes approximately 42ms on a UC8253 X3.

and `docs/device-specifications.md`:

> An incorrect image can drive the wrong GPIOs and damage hardware.

Those values are **scraped, never hand-typed** — see `tools/gen_luts.py`. LUT
bytes are drive-voltage tables: a wrong byte applies the wrong voltage to
pixels for hundreds of milliseconds, and upstream documents real pixel damage
on this controller when it is driven off-spec. The generator rejects any table
that is not exactly 42 bare hex literals, and drops an entire waveform set if
one of its five planes is missing, because a half-present set looks usable.

Consequences of taking these rather than deriving them:

- No guesswork on voltages, which is the one place a firmware bug is permanent.
- The button buckets come from a published measurement, not from reading a
  serial console on one unit and hoping it generalises.
- If upstream corrects a value, `tools/gen_luts.py` picks it up on the next run
  and the 42-byte assertion tells us if the format changed under us.

## Fonts

`src/gfx_font.h` is generated by `tools/font_gen.py` from fonts already
installed on the build machine (Helvetica Neue from `HelveticaNeue.ttc`, Arial
Bold from `Supplemental/Arial Bold.ttf`), rendered to 1-bit bitmaps.

No font files are redistributed by this repository: the output is a monochrome
bitmap strike generated locally, and the generator is re-runnable on any machine
that has the faces. The chosen faces and their TTC indices are written into the
generated header, because regenerating on a machine without them silently
substitutes fallbacks.

Helvetica and Arial are trademarked/licensed typefaces. If this project is ever
distributed beyond personal use, swap `REG`/`BOLD_PATH` in `tools/font_gen.py`
for a Libre OFL face (e.g. Inter, or Roboto for the bold suits — note the
suit-solidity assertion must still pass, since Helvetica-class faces ship
outline suit glyphs and will be rejected).

## No assets from the device

Nothing from the Xteink X3's stock firmware is copied into this repository.
The stock 16 MB dump lives outside the repo in `~/XteinkX3-backup/` and on a
second physical disk; it is a vendor firmware image and is not redistributed.
